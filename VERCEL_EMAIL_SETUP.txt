J.HINTON VERCEL EMAIL ENVIRONMENT VARIABLES

Add these in Vercel > Project > Settings > Environment Variables:

SMTP_HOST=smtp.hostinger.com
SMTP_PORT=465
SMTP_USER=ordersupport@j-hinton.com
SMTP_PASS=YOUR_MAILBOX_PASSWORD
SMTP_FROM=J.HINTON <ordersupport@j-hinton.com>

Keep your existing:
STRIPE_SECRET_KEY
STRIPE_WEBHOOK_SECRET
STRIPE_ALLOWED_COUNTRIES
STRIPE_AUTOMATIC_TAX

Apply the SMTP variables to Production (and Preview if you use Preview), then redeploy.

Important:
- Do not commit SMTP_PASS to GitHub.
- Do not send the mailbox password in ChatGPT.

Order notification recipients:
ADMIN_ORDER_EMAIL=ordersupport@j-hinton.com (existing recipient; preserve your current value if different)
ADDITIONAL_ORDER_EMAILS=houseofjhinton@gmail.com

The backend defaults to also notifying houseofjhinton@gmail.com if ADDITIONAL_ORDER_EMAILS is not set. Separate multiple additional addresses with commas. Each paid order sends one admin email addressed to both recipients. Existing customer confirmations are unchanged.
